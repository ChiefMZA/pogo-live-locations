# POGO Live Locations

Public, read-only GitHub Pages view of the **Hotspots** and **Timezones** lists from POGO Account Switcher.

The page displays live local time in the visitor's browser, groups locations by their current UTC offset, and follows daylight-saving changes through each location's IANA timezone. The desktop app refreshes `data/locations.json` whenever its saved data changes. Commit and push that file with GitHub Desktop to publish app edits.

Only public location names, coordinates, timezones, and country codes are exported. Account, device, activity, and other private app data are never placed in this folder.
